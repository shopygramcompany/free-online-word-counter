## 🌟 Key Features
- **Accurate Tokenization**: Matches Microsoft Word and Google Docs standards (hyphenated words and contractions count as one; em dashes and decimals split appropriately).
- **100% Client-Side Privacy**: Runs completely inside your browser's local memory using Vanilla JavaScript. Zero text or documents are ever uploaded to any server.
- **Document Dropzone**: In-browser drag-and-drop parsing for .docx, .rtf, .txt, and .md files via HTML5 FileReader APIs.
- **Social Media Cutoff Indicators**: Live countdown pills for X / Twitter (280), LinkedIn hook (210), Instagram caption (125 / 2,200), and SMS (160).
- **1-Click Text Transformers**: UPPERCASE, lowercase, Title Case, Sentence case, camelCase, slug-url, clean whitespace, and remove blank lines.
- **Goal & Limit Tracker**: Set custom word/character goals with dynamic visual progress bars.
- **Keyword Density Analyzer**: Real-time N-Gram frequency analysis for single words (×1), bigrams (×2), and trigrams (×3).
